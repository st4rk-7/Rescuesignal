# RescueSignal: shared guide

EC5203 Machine Learning mini-project, Group 21.
We classify disaster tweets (HumAID Set 1) and test the models on **disaster events they never saw in training**.

This repo holds only the common guide: **[step_by_step_plan.md](step_by_step_plan.md)**.

How to use it:
1. Read "How to learn with this guide" at the top. The focus is **concepts first, code second**.
2. Work through the phases in order, one step at a time.
3. Keep your own code, data and notes on your own machine. The dataset is downloaded in step 0.3.
